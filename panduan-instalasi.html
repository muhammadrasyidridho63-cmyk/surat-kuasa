A. Backend · Google Apps Script

Server aplikasi REST API. Berjalan gratis di akun Google Anda.

  1. 1

    Buat proyek Apps Script baru

    1. Pastikan browser sedang masuk dengan akun Google yang akan menjadi pemilik database pengadilan.
    2. Klik tombol di bawah untuk membuka proyek baru.
    3. Klik judul Proyek tanpa judul di kiri atas, ganti menjadi E-Surat Kuasa Backend, lalu klik Ganti nama.
    Buka Apps Script ↗
  2. 2

    Tampilkan berkas appsscript.json

    1. Di bilah kiri Apps Script, klik ikon roda gigi ⚙ Setelan proyek.
    2. Centang Tampilkan file manifes "appsscript.json" di editor.
    3. Kembali ke editor dengan klik ikon < > Editor. Sekarang terlihat berkas appsscript.json dan Kode.gs.
  3. 3

    Tempel 5 berkas backend

    Gunakan stasiun berkas di bawah. Kotak kuning selalu menunjukkan berkas berikutnya yang harus ditempel. Ulangi gerakan ini:

    1. Di Apps Script, klik tanda + di samping Berkas → pilih Skrip.
    2. Tekan Salin nama di sini, lalu di kotak nama Apps Script tekan Ctrl+V → Enter.
    3. Tekan Salin isi di sini. Di Apps Script klik area kode, tekan Ctrl+A (pilih semua) lalu Ctrl+V.
    4. Tekan Ctrl+S untuk menyimpan, lalu klik Sudah, lanjut di sini.

    Untuk appsscript.json: klik langsung berkasnya di daftar kiri Apps Script, ganti isinya dengan tombol Salin isi. Untuk Kode.gs bawaan: ganti namanya menjadi Kode lewat tombol ⋮ → Ganti nama.

      0 berkas ditempel
    • 4

      Jalankan setupAppEnvironment sekali

      Fungsi ini otomatis membuat folder Google Drive (Berkas & Arsip PDF), Spreadsheet Database dengan 6 tabel PRD, akun staf/pejabat awal, dan konfigurasi Script Properties.

      1. Buka berkas Setup.gs di Apps Script.
      2. Di toolbar atas, pada pilihan fungsi (di samping tombol ▷ Jalankan), pilih setupAppEnvironment.
      3. Klik ▷ Jalankan. Saat muncul Otorisasi diperlukan, klik Tinjau izin → pilih akun Google Anda.
      4. Klik Lanjutan → klik Buka E-Surat Kuasa Backend (tidak aman) → Izinkan.
      5. Tunggu hingga panel Log eksekusi di bawah menulis SETUP SUKSES!.
    • 5

      Terbitkan sebagai Aplikasi Web (Web App)

      1. Klik tombol biru Deploy di kanan atas → Deployment baru.
      2. Klik ikon roda gigi ⚙️ di samping Pilih jenis → Aplikasi web.
      3. Isi: Deskripsi v2.4.0 REST API · Jalankan sebagai Saya · Yang memiliki akses Siapa saja.
      4. Klik Deploy, lalu salin URL Aplikasi web yang berakhiran /exec.

      Hak akses wajib: Siapa saja (Anyone) agar pemohon publik dapat mendaftar tanpa harus login akun Google institusi.

    • 6

      Tempel URL Web App di sini lalu uji

    Jika ada masalah
    Klik pertanyaan yang sesuai dengan gejala yang Anda lihat.
    
        
    
          
    Aplikasi menampilkan "Mode Demo" atau data belum terhubung ke Google Sheets
    Periksa file js/config.js. Pastikan Anda sudah mengisi GAS_URL dengan URL Web App Anda yang berakhiran /exec, bukan URL editor skrip.
    
          
    Pendaftaran gagal: "Gagal memuat / CORS error"
    Pastikan saat Deploy Web App Anda memilih Yang memiliki akses: Siapa saja (Anyone). Jika diatur hanya domain Anda, browser publik akan ditolak.
    
          
    PIN Pengesahan Pejabat ditolak
    PIN bawaan default adalah 123456. PIN dapat diubah kapan saja melalui menu Script Properties di editor Apps Script dengan kunci PEJABAT_PIN.
    
          
    git push ditolak: "Password authentication is not supported"
    GitHub mewajibkan penggunaan Personal Access Token (PAT) sebagai pengganti password. Buat token di menu Settings > Developer Settings > Personal access tokens di GitHub.
    
          
    Saya mengubah kode backend .gs, tetapi perubahan tidak tampak
    Di Google Apps Script: klik Deploy → Kelola penerapan (Manage deployments) → klik ikon pensil Edit → ubah Versi: Versi baru (New version) → klik Terapkan. URL /exec akan tetap sama.
